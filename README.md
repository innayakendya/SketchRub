## Installation

1. Clone the repository: `git clone https://github.com/innayakendya/SketchRub.git`
2. `cd SketchRub`
3. Install in editable mode: `pip install -e .`

## Configuration

SketchRub is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
